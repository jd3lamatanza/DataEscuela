# DataEscuela

Página de prueba para validar la conexión entre GitHub Pages y Supabase.

## Publicar

Subí estos archivos al repositorio `jd3lamatanza/DataEscuela` y habilitá GitHub Pages desde la rama principal y la carpeta raíz.

La página prueba:

- Respuesta de la API pública de Supabase.
- Existencia y lectura de `public.roles` mediante REST.

Solo contiene la publishable key. No publiques una secret key ni una cadena PostgreSQL.
